# HR Analytics Dashboard | Excel, SQL & Tableau

## HR Analytics Project

An end-to-end HR Analytics project using **Microsoft Excel, MySQL and Tableau** to analyze employee data, understand workforce distribution, and identify employee attrition patterns.

This project covers data preparation, SQL-based data cleaning, joining multiple datasets, and interactive dashboard development using Tableau.

## 📊 Project Overview

The HR Analytics Dashboard provides insights into employee information, department-wise workforce distribution, job satisfaction, and employee attrition.

The main objective is to transform raw HR datasets into meaningful information that helps understand workforce trends and supports data-driven HR decisions.

The project follows an end-to-end data analytics workflow, from raw data preparation to interactive visualization.

---

## 🎯 Project Objectives

- Analyze overall employee distribution.
- Understand employee attrition patterns.
- Calculate employee attrition rate.
- Analyze department-wise employee distribution.
- Explore employee job satisfaction levels.
- Analyze employee distribution across age groups.
- Identify workforce trends using interactive dashboards.

---

## 🗂 Dataset Description

The project uses two original HR datasets in Excel format.

**Original Datasets:**
- HR_1.xlsx
- HR_2.xlsx

The datasets contain employee-related information used for workforce and attrition analysis.

The combined dataset is used to perform further analysis and develop the Tableau dashboard.

---

## 🧹 Data Cleaning Using SQL

MySQL was used for data preparation, cleaning, and combining the original datasets.

The following operations were performed:

- Imported Excel datasets into MySQL.
- Joined both tables using SQL JOIN operations.
- Checked missing and NULL values.
- Identified and handled duplicate records.
- Performed data validation.
- Prepared the cleaned and merged dataset for visualization.

**SQL Concepts Used:**
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- NULL Handling

## 📈 Dashboard Features

The interactive Tableau HR Analytics Dashboard includes:

**Key Performance Indicators (KPIs):**
- Total Employees

**Visualizations:**
- Department-wise Employee Distribution
- Education Field Analysis
- Job Role and Job Satisfaction Analysis
- Employee Attrition Analysis
- Age Group Distribution
- Attrition by Employee Category

**Interactive Filters:**
- Department
- Gender
- Job Satisfaction

## 🔄 Project Workflow

1. Collected and explored the original HR datasets.
2. Prepared the Excel datasets for database import.
3. Imported both datasets into MySQL.
4. Joined the tables using SQL.
5. Performed data cleaning and validation.
6. Prepared the final merged dataset.
7. Connected the data to Tableau.
8. Created an interactive HR Analytics Dashboard.
9. Analyzed employee attrition and workforce distribution.
